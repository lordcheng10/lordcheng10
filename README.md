### 🧭 About me

I work on the plumbing that moves data at **trillion-message scale** — the parts of the stack
where one bad cache eviction policy costs a cluster its tail latency.

- 🧩 **Apache Pulsar Committer** — broker load balancing (traffic-based `BundleSplit`),
  Broker Cache redesign with mark-delete eviction (hit rate 60% → 90%), BookKeeper stability fixes
- 📨 **175+ pull requests** across the Apache ecosystem — Pulsar (109), BookKeeper (42), Kafka (20), APISIX (4)
- 🏗️ **Middleware & AI infrastructure architect** — API gateway platforms on APISIX, service-governance
  control planes, model-key lifecycle & AI gateway infrastructure
- 🎤 Speaker at **ApacheCon Asia 2022** and **Pulsar Summit Asia**
- 📍 Hong Kong SAR · English / 中文
